# V4.3 Database Migration Plan

No SQL has been executed. These are reviewable migration files for a development/non-production database only.

## Migration rules

- Additive and idempotent wherever practical.
- No `DROP TABLE`, `TRUNCATE`, destructive `DELETE`, or destructive `ALTER`.
- Production policies are not changed by this candidate.
- Every policy change must document current policy, proposed policy, affected table/role, and rollback.
- Existing V4.2 SQL files remain frozen references.

## Proposed order

1. `0001_v43_additive_safety.sql` — OTP metadata/table and payment idempotency metadata.
2. `0002_v43_roles_and_rls_proposal.sql` — proposal-only role/capability policies; not approved for production.
3. `0003_v43_audit_events.sql` — additive audit event table and indexes.
4. `0004_v43_theme_config.sql` — allowlisted, data-only app/festival theme configuration.

## Rollback

Because these migrations are additive, rollback means disabling the new code paths and leaving the additive objects unused. Any future destructive cleanup requires a separate approval and a separately reviewed migration.
