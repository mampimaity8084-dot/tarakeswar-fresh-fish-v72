# GitHub Setup — V7 Final Master

1. Create a private GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Do NOT upload `.env` or real API keys.
4. Keep `.env.example` as the safe template.
5. Use GitHub history/tags for releases:
   - `v7-final-master`
   - `v7.1`
   - `v7.2`
6. Protect the main branch when the project becomes stable.

`V7 Final Master — production-ready baseline`
