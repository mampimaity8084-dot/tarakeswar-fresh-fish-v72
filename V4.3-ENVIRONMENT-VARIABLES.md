# V4.3 Environment Variables

No production environment variables were changed.

## Existing server values

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY` or legacy `SUPABASE_SECRET_KEY`
- `RAZORPAY_KEY_ID`
- `RAZORPAY_KEY_SECRET`
- `ADMIN_EMAILS`
- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT`
- WhatsApp/Meta variables used by the existing functions

## V4.3 rules

- Use separate non-production values for candidate testing.
- Never place service-role, Razorpay secret, VAPID private, or WhatsApp access tokens in browser files.
- Do not change production values during this phase.
