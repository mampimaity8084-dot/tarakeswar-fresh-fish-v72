# Tarakeswar Fresh Fish V5.3 — Cloudflare Environment Variables

Required:
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY (or legacy SUPABASE_SECRET_KEY)
- RAZORPAY_KEY_ID
- RAZORPAY_KEY_SECRET
- ADMIN_EMAILS

AI (choose one):
- OPENAI_API_KEY
- OPENAI_MODEL (optional; default: gpt-5.6-luna)

Legacy generic AI provider (optional alternative):
- AI_API_URL
- AI_API_KEY

Push (optional):
- VAPID_PUBLIC_KEY
- VAPID_PRIVATE_KEY
- VAPID_SUBJECT

WhatsApp 1:1 (optional):
- WHATSAPP_ACCESS_TOKEN
- WHATSAPP_PHONE_NUMBER_ID
- WHATSAPP_GRAPH_VERSION (example: v25.0)
- WHATSAPP_TEMPLATE_LANG (optional)

WhatsApp Groups API (optional):
- WHATSAPP_GROUP_ID

Important: never put service-role, Razorpay secret, OpenAI key, VAPID private key, or WhatsApp access token in frontend files.
