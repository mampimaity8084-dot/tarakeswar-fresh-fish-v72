# Tarakeswar Fresh Fish V5.1

## Smart Automation & App Control

Additive upgrade on top of V5/V4.3. Existing customer, admin, delivery, wallet, payment, OTP, GPS, banner and rewards code is preserved.

### Added
- Global 30-second auto-refresh fallback and visibility refresh.
- PWA version manager via `app-version.json`.
- Universal Admin App Center with QR generation, copy, share and save.
- Install/share/copy/refresh quick tools on all app surfaces.
- Animated logo branding.
- Flowing branded tagline marquee.
- Easier customer profile photo capture and preview.
- Admin live system status panel.
- Versioned service-worker caches for customer, delivery and admin.

### Safety
- No Supabase migration is required for the V5.1 client enhancements.
- Existing server functions are not replaced.
- Optional features fail gracefully if a browser capability is unavailable.
