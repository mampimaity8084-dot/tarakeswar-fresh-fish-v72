Tarakeswar Fresh Fish V2.3 — Next-Day Commerce Upgrade

Features:
- Add to Cart + saved cart drafts visible to Admin
- Next-day delivery with Morning / Evening slot selection
- Order confirmation screen for customer
- Order appears immediately in Admin database/dashboard
- COD with configurable advance percentage
- Full online payment with configurable discount
- Order tracking by Order ID + mobile
- Delivery status flow: New > Confirmed > Preparing > Packed > Out for Delivery > Delivered
- Delivery partner page can update live GPS location while order is Out for Delivery
- Customer tracker polls secure RPC for current status/location
- Header tagline: “আপনার সাথে… আপনার পাতে…!”
- “WEEKLY AUTO” replaced by “MEMBER UPDATE”

IMPORTANT:
1) Run UPGRADE_V2_3_NEXTDAY.sql in Supabase SQL Editor once.
2) Deploy this whole folder/ZIP to Cloudflare.
3) In Admin > Settings, set COD advance %, online discount %, and UPI ID.
4) In-app order tracking works without WhatsApp Cloud API.
5) Fully automatic WhatsApp confirmation/status messages require Meta WhatsApp Business Platform credentials/templates.
