Tarakeswar Fresh - Blinkit-style 3 App Prototype

1) index.html      = Customer App
2) admin.html      = Admin / Seller App
3) delivery.html   = Delivery Partner App

Categories included:
Fish, Seafood, Meat, Eggs, Milk, Bakery

Admin features:
- Add products
- Set category, price, unit, stock
- Delete products
- Accept latest order

Customer features:
- Search and category filters
- Add to cart
- WhatsApp checkout to 8100227692

Delivery features:
- View latest order
- Picked Up / Delivered status

This is a front-end prototype using browser localStorage.
For a real Blinkit-like production app, add:
- database + backend API
- user login / OTP
- online payment
- delivery location / maps
- real-time order tracking
- push notifications
- inventory sync
- admin analytics
- delivery partner login
