TARAKESWAR FRESH FISH — FINAL STORE READY V4.2
================================================

এই build-এ final launch-এর আগে যেসব gap ধরা পড়েছিল সেগুলো fix করা হয়েছে:

1. Minimum order ₹499
   - Customer app-এ cart ₹499-এর নিচে হলে স্পষ্টভাবে দেখাবে কত টাকা/কত product আরও add করতে হবে।

   - তাই customer bypass করে ₹499-এর নিচে order confirm করতে পারবে না।

2. Fresh Wallet
   - Admin Customer Dashboard থেকে customer wallet-এ recharge করা যাবে।
   - Recharge-এর প্রতিটি entry wallet_ledger-এ থাকবে।
   - Customer My Fresh Hub-এ balance দেখতে পারবে।
   - Wallet payment-এ 2% discount থাকবে।
   - Wallet order confirm হলে server-side wallet balance থেকে payable amount automatic minus হবে।
   - Wallet spending-এর আগে একই device থেকে অন্তত একটি verified paid order থাকা বাধ্যতামূলক।

3. Customer profile photo
   - Customer My Fresh Hub থেকে নিজের profile photo upload করতে পারবে।
   - Admin Customer Dashboard থেকেও customer photo upload করা যাবে।
   - Photo Supabase customer-avatars bucket-এ যাবে; browser database-এ base64 রাখা হবে না।

4. Customer Dashboard
   - Admin title: Tarakeswar Fresh Fish — Customer Dashboard
   - Customer name + mobile + area + photo + points + wallet + referral + order count দেখা যাবে।
   - এখান থেকেই Wallet recharge করা যাবে।

5. Combo auto-scroll
   - Combo & Offer Zone-এর manual View All থাকবে।
   - Combo cards automatic horizontal scroll করবে।
   - Existing top offer slider-এর auto slide থাকবে।

6. Delivery Partner
   - Login/logout timestamp এখন save হবে।
   - Delivery dashboard-এ partner name, base pay, surge এবং calculated bonus দেখা যাবে।
   - Delivered order হলে assigned partner-এর earnings/bonus একবার automatic যোগ হবে।
   - Final order status log-এ Delivery Partner-এর নাম লেখা হবে।
   - Existing QR magic login retained.

7. App Install
   - Customer/Admin/Delivery manifest-এ proper 192x192 ও 512x512 PNG icons দেওয়া হয়েছে।
   - Service-worker cache version bump করা হয়েছে যাতে পুরনো cached build আটকে না থাকে।
   - Customer Install button এখন একটিই install handler ব্যবহার করে।
   - IMPORTANT: Chrome নিজে beforeinstallprompt না দিলে কোনো website JavaScript দিয়ে Android-এর system install dialog জোর করে খুলতে পারে না। তখন Chrome ⋮ → Add to Home screen / Install app ব্যবহার করতে হবে।

8. WhatsApp Auto Banner
   - Auto Banner generation ঠিক আছে এবং scheduled function প্রতিদিন banner generate করতে পারে।
